# 标签与防火墙

标签可关联用户和用户组。用户的有效标签由直接关联标签与所属活动组的标签组成。

## 标签的用途

- **中心防火墙**：标签可作为规则来源，按当前成员动态计算地址集合。
- **Mesh 路由**：对端可按组和标签限制哪些用户接收站点 LAN 路由。组与标签为 OR 关系；两者都未选择时，对所有活动用户下发。
- **对端防火墙**：标签可作为动态来源。每个对端使用独立 ipset，iptables 通过集合匹配源地址。

## 同步规则

- 标签成员、用户状态、CCD 地址、用户切组及组网段变化，会刷新受影响的中心规则、Mesh 路由和远端规则。
- ipset 采用声明式 reconcile：先准备新集合，再 swap 更新；失败回滚，成功后清理不再引用的集合。
- 对端同步失败会保留待同步状态，可在「防火墙 → 对端远端」重新推送。
- 没有有效成员时不生成无来源限制的放行规则。

## 删除与注意事项

标签仍被用户/组关联、中心防火墙、Mesh 路由或远端防火墙引用时，不允许删除。解除所有关联和引用后才可删除。

远端链包含动态标签规则时，手动执行「从对端拉取」会把远端展开规则作为普通规则接管，可能丢失本地动态标签绑定；确认前先检查提示并备份远端规则。
