# 对端 Mesh 路由与远端防火墙支持标签

## 背景

当前标签已支持用户/组关联和中心防火墙规则，但对端 Mesh 路由可见范围仅支持组，对端远端防火墙结构化新建仅支持组/用户。标签成员变化也没有贯通 Mesh CCD 和远端防火墙数据面。

## 目标

- 对端 Mesh 路由可见范围支持组和标签，组/标签采用 OR 关系。
- 对端远端防火墙规则支持以标签作为动态源地址集合。
- 标签成员、用户状态/地址、切组、组状态/子网变化后，自动重新计算相关 Mesh 路由和远端规则。
- 标签被对端路由或远端规则引用时禁止删除。
- 对端删除时清理本地远端防火墙缓存。

## 非目标

- 不改变中心防火墙现有 tag/ipset 规则语义。
- 不在远端对端强制安装 ipset；远端标签规则先按当前有效地址展开为 iptables 行。
- 不支持对任意远端原始 iptables 规则自动反向识别标签归属。
