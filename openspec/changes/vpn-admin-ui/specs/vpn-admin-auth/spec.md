# Spec Delta

## Purpose

为 VPN 管理后台提供默认关闭、由配置显式启用的单管理员登录保护，同时保持未配置认证时的现有部署行为，并为后续多管理员与 SQLite 迁移保留清晰边界。

## ADDED Requirements

### Requirement: 登录保护由完整凭据配置显式启用
系统 SHALL 仅在配置文件同时存在非空管理员用户名和有效密码哈希时启用后台登录保护；两个字段均未配置时 SHALL 关闭登录保护并保持现有页面访问方式。

#### Scenario: 默认未配置凭据
- **WHEN** 管理员用户名和密码哈希均未配置
- **THEN** 系统不显示登录页、不要求会话认证，并允许按现有规则访问后台页面

#### Scenario: 完整配置凭据
- **WHEN** 管理员用户名和有效密码哈希均已配置
- **THEN** 系统启用登录页、会话和后台路由保护

#### Scenario: 凭据配置不完整或无效
- **WHEN** 仅配置用户名或密码哈希，或者密码哈希格式无法识别
- **THEN** 系统在启动阶段给出明确错误并拒绝以未受保护模式继续运行

### Requirement: 管理员密码不得以明文持久化
系统 SHALL 使用 Argon2 密码哈希验证管理员口令，配置文件、日志、页面和异常信息均不得持久化或回显明文密码。

#### Scenario: 生成管理员凭据
- **WHEN** 运维人员通过受支持的命令设置或更新管理员密码
- **THEN** 系统只输出或写入可用于配置的 Argon2 哈希，并避免在日志中记录明文口令

#### Scenario: 验证错误密码
- **WHEN** 登录提交的用户名或密码不正确
- **THEN** 系统返回不区分用户名与密码的统一失败提示，并且不记录提交的密码

### Requirement: 受保护页面必须要求有效会话
系统 SHALL 在认证启用时保护全部 NiceGUI 管理页面，只允许登录页、NiceGUI 必需内部资源和明确列入白名单的非敏感静态资源匿名访问。

#### Scenario: 未登录访问后台页面
- **WHEN** 未认证访问者请求任一受保护后台 URL
- **THEN** 系统跳转到登录页并保存经过校验的原始站内目标路径

#### Scenario: 登录后返回原页面
- **WHEN** 管理员从受保护页面跳转到登录页并成功登录
- **THEN** 系统返回原始站内页面；非法、站外或缺失的目标地址回退到默认后台入口

#### Scenario: 静态资源匿名访问
- **WHEN** 未认证访问者请求后台 CSS、公开图标或本地第三方浏览器库
- **THEN** 系统允许加载这些非敏感资源，且静态目录中不存在凭据、私钥、业务数据或运行时配置

### Requirement: 登录会话可以安全建立和撤销
系统 SHALL 使用独立、持久且不可预测的会话密钥签名会话，提供登录、退出和过期处理，并在退出后清除认证状态。

#### Scenario: 登录成功
- **WHEN** 管理员提交正确凭据
- **THEN** 系统建立有过期时间的认证会话、记录不含敏感值的成功审计信息并进入目标页面

#### Scenario: 主动退出
- **WHEN** 管理员点击退出
- **THEN** 系统清除当前认证状态并跳转到登录页

#### Scenario: 会话过期或签名失效
- **WHEN** 已登录会话超过有效期或无法通过签名校验
- **THEN** 系统按未登录状态处理并要求重新认证

### Requirement: 登录尝试必须具备基本滥用保护
系统 SHALL 对连续失败登录进行按来源和时间窗口限制，使用统一错误反馈，并记录不含密码的失败事件。

#### Scenario: 连续登录失败
- **WHEN** 同一来源在限制窗口内连续提交错误凭据达到阈值
- **THEN** 系统暂时拒绝继续尝试并显示通用稍后重试提示

#### Scenario: 限制窗口结束
- **WHEN** 登录限制窗口结束
- **THEN** 系统允许重新尝试且不泄露先前失败的具体凭据判断结果

### Requirement: 现有非页面认证语义保持独立
系统 SHALL 将后台页面登录与现有 API Basic 认证、一次性下载链接和其他令牌机制分开处理，不得因启用或关闭后台登录而隐式放宽这些接口。

#### Scenario: 后台登录已启用
- **WHEN** 客户端访问现有 API 或一次性下载地址
- **THEN** 系统继续执行该接口原有的认证或令牌校验，而不是仅依赖后台页面会话
