# 安全与身份认证

## 设备绑定

系统设置支持三种模式：

| 模式 | 行为 |
|---|---|
| `weak_log` | 仅记录，不拒绝连接 |
| `weak_fingerprint` | 使用可用的设备指纹进行通用绑定 |
| `strict_hwaddr` | 必须提供硬件 MAC，否则拒绝 |

设备绑定豁免需同时打开全局开关，并在用户组或标签上配置。用户直接标签、所属组标签或组自身配置命中任一项即可豁免。关闭全局开关只停用豁免，不删除原配置。

豁免只影响设备指纹检查，不绕过证书、用户状态或防火墙策略。

## 企业 SSO

- 默认关闭；启用后可选择全员认证，或仅对明确开启 SSO 的用户组/标签强制认证。
- 支持钉钉和企业微信。企业身份由服务端 OAuth 响应核验，并与后台企业白名单匹配。
- 办公系统账号不需要存在于 NiceVPN 用户表，也不会改变 VPN 用户、组或防火墙权限。
- SSO 成功的连接只记录设备信息，不执行设备绑定拒绝；未要求 SSO 的连接继续原设备绑定策略。
- 不支持 WebAuth 的客户端不能绕过强制 SSO，应使用未要求 SSO 的组或标签。
- 会话离线复用窗口为 1 小时；在线连接持续续期。企业白名单或应用配置变更后，旧授权不能继续绕过新策略。

## 部署安全

- 管理端 8880 不应直接暴露公网；API / OAuth 回调使用 8881。
- HTTP 可用于可信内网测试；公网登录应使用 HTTPS。
- OpenVPN Management Socket 仅允许本机受控访问。
- SSO 密钥文件为 `data/sso_provider_master.key`，权限应为 0600；备份时必须与 `data/nicevpn.db` 一起保存。
- 不记录 OAuth Code、Token、App Secret 或一次性认证事务凭据。
