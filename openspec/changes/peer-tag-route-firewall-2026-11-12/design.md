# 设计：对端路由与远端防火墙标签联动

## Mesh 路由

PeerInstance 新增 `mesh_route_visible_tag_ids`，保留旧字段兼容。计算某用户的可见 LAN 时：
- 可见组和可见标签都为空：对所有活动用户下发。
- 命中任一可见组，或用户直接标签/活动组继承标签命中任一可见标签：下发。
- 组和标签之间是 OR，不是 AND。
- 活动组继承标签；非活动组不向用户贡献组标签。
- 停用用户 CCD 移除 Mesh push 块；启用后重新计算。
- peer wire snapshot 同时包含 LAN、组 ID、标签 ID，确保只有可见范围变化时也刷新 CCD。

TagRepository 提供一次读取所有 user_tags/group_tags 的批量方法，避免每个用户分别查询造成 N+1。

## 远端防火墙

远端链缓存允许保存一条不含 raw rest 的逻辑标签行：
`tag_binding={tag_id, tag_name, action, protocol, dest_ip, dest_port}`。

每次推送时，解析 TagService 当前有效成员，调用现有远端规则生成器展开成 iptables rest 列表。标签无有效地址时不生成规则，禁止出现无源限制的 ACCEPT。缓存读写只保留白名单元数据字段。

标签成员或其用户/组状态与地址变化时：
- 检查哪些对端缓存引用了受影响标签。
- 先持久化 pending_sync，再异步通过 SSH 重新展开和推送。
- SSH 失败保留 pending_sync 与错误信息；页面可手动再次推送。
- 进入远端防火墙页时，如果缓存含逻辑标签规则，跳过自动拉取；手动拉取需二次确认，因为远端 raw chain 无法反推出标签归属。

远端规则保持一行逻辑记录，UI 可编辑、启停、删除、排序。推送时才展开为多行 iptables 规则。

## 标签引用可见性

- 标签详情页分别统计中心规则和对端引用；对端引用包含 Mesh 路由范围与远端防火墙逻辑规则。
- “已引用”筛选包含中心规则和对端引用；仍被引用的标签禁用删除入口，并在服务层二次校验。
- 详情页可查看引用它的对端名称、引用类型、远端规则动作/协议/目标和启停状态。

## 生命周期

- 标签删除前检查中心规则、peer Mesh tag IDs、远端缓存 tag_binding。
- 删除 peer 时清理远端链缓存和 prepush 备份。
- 用户/组标签关联变化刷新中心防火墙、引用标签的 Mesh CCD 和远端规则。
- 远端标签规则展开前折叠被组 CIDR 覆盖的单 IP，并在一次推送内复用 CCD 地址快照；停用的逻辑标签规则不触发成员变更 SSH 刷新。
